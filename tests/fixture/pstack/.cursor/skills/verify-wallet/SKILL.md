# verify-wallet

## Launch

Nothing to launch: the wallet is a short-lived CLI.

## Doctor

Run `python3 -m wallet --version` and require `wallet 1.0`.

## Drive

Run `python3 -m wallet withdraw BALANCE AMOUNT` from the repo root.

## Evidence

Keep the command, the exit code and the output of each step.

## Cleanup

Nothing to stop. Keep the evidence.
