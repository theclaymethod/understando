The first two checks apply the developer’s fresh-play rule to two listener histories. Using the existing player for the repeat attempt is a proposed way to catch access that survives disabling the address. The engineer suggested hiding the player. Either a hidden control or a visible control that reports refusal is compatible with the developer’s playback requirement.
