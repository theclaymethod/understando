<p>{"This PR replaces four document pipelines with one harness, "}<code>{"cr docgen --kind {note,uap,fmm,4h}"}</code>{"."}</p>
<p>{"Before this PR, each pipeline had its own CR loader, checks, repair and judge wiring."}</p>
<p>{"The harness runs one loop for each kind. It projects a draft and reflects on it. An editor repairs the findings, and the loop keeps or reverts each round."}</p>
<p>{"Type pins and a boundary script make the pipeline rules static, and anti-gaming rules stop the editor from hiding a problem without a repair."}</p>
<p>{"The result is one set of contracts and fewer failures in the note, at a higher cost for each document."}</p>
